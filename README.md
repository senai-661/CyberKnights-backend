Setup
- Copy `.env.example` to `.env`
- Fill `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`, and `DB_NAME`
- Run the SQL in `infra/sql/init.sql` against the configured database
- If `.env` is missing, the app defaults to: `DB_USER=postgres`, `DB_PASSWORD=postgres`, `DB_HOST=localhost`, `DB_PORT=5432`, `DB_NAME=cyberknights`
